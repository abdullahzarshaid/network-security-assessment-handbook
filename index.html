The companion tool: PostureKit

The host assessment toolkit specified in Part VII is published as open source (MIT). A PowerShell collector reads 45 evidence sources from an authorised Windows host and seals them with SHA-256; a Python analyzer evaluates 45 rules and the patch state against Microsoft's free vulnerability data; importers add wireless, hardening-audit and network-scan planes. It identifies, it never exploits, and it never assigns severity on its own.
